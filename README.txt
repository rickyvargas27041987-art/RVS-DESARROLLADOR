RVS DESARROLLADOR — Landing page
=================================

Archivos
--------
- index.html
- styles.css
- script.js

Antes de publicar
-----------------
1. Abrí script.js.
2. Cambiá:
   whatsappNumber: "549XXXXXXXXXX"
   por tu número real en formato internacional, sin +, espacios ni guiones.
3. Cambiá instagramUrl por el Instagram de RVS.
4. Si querés, después reemplazamos las ilustraciones CSS de los proyectos por capturas reales.

Publicación
-----------
Es un sitio estático. Podés subir estos tres archivos a un repositorio de GitHub
y publicarlo en Vercel sin necesidad de base de datos.

Estructura comercial
--------------------
- Presentación clara
- Servicios
- Proyectos reales
- Proceso de trabajo
- Llamado a la acción
- WhatsApp / Instagram

La página es responsive para PC y celular.
